## 先说清楚：广州 BGP 到香港的 IEPL 独享带宽是什么

拆开看这条链路，每一截都有具体含义：

- **入口（广州端）**：腾讯广州八线 BGP。也就是说你在广东本地连入时，电信、联通、移动八线动态 BGP 会就近调度，不需要你自己挑运营商线路。
- **中间（传输段）**：IEPL，也就是点对点的国际专用内网线路。和走公网的普通 VPS 不同，这一段不经过公共互联网，不受跨境公网拥塞和 QoS 影响。
- **出口（香港端）**：香港 BGP 出口，向外访问目标平台。

官方给出的端内延迟参考是 1~2ms。这个数字只覆盖广州入口到香港出口这一段专线，你本机到广州入口、香港到目标网站的延迟要另外算，所以实际 ping 出来的数字一定比 2ms 大。第三方测评站 vps.dance 对广港 IEPL 的实测是：广州入口 TCP ping 平均电信约 34ms、联通约 33ms，这个量级对华南用户来说属于正常且不错的表现。

每台机器分配独立 IPv4 一对（一个入口 IP 加一个出口 IP），进和出是分开的两个 IP，这点对需要双端独立 IP 的业务比较关键。

## 独享带宽和共享带宽，差的不只是钱

Mkcloud 的广港 IEPL 分成两种计费方式，这也是选型时最容易纠结的地方：

**共享带宽（流量计费）**：带宽是峰值速率，比如 200Mbps 峰值不代表你能持续跑满 200M。流量按上行和下行双向统计，月流量用完会暂停，可以自助购买流量重置或提交工单补差价升级。优点是便宜，适合流量不大、偶尔传传文件的场景。

**独享带宽（带宽计费）**：你买的是确定的持续速率，比如 5M 独享就是这条 5M 带宽只给你用，流量不限量。官方知识库原话是「不限流量也不代表无限速」——独享的速就是你买的那个数字。适合需要长时间持续上传、对带宽有硬性要求的业务。

一句话判断：如果业务是间歇性的、流量可预测，共享够了；如果是持续跑满的传输任务、多任务并发，或者被晚高峰共享带宽坑过，才需要考虑独享。独享入门 5M 每月 500 元起，这个价格不是给轻度用户准备的，别为了「听起来更稳」多花冤枉钱。

## 独享带宽到底适合什么业务

从实际能力出发，这类产品能做的事很明确：在 VPS 上操作后台、访问 API、上传文件、做客户端测试。交付形态是「连入口、从出口向外访问」。

同时有几条硬限制要提前知道，别等买完才发现用不了：

> 出口不支持外部连入。也就是说不能拿来部署公开的游戏服务端、面向买家的网站或接收支付回调，这类需要「被访问」的业务和这个产品方向不匹配。

香港出口也不等于美国 IP。如果你的目标平台对 IP 归属地有要求（比如需要美国本土 IP 的业务），广港线解决不了这个问题，得看对应方向的产品。另外，金融类或其他重要业务要自己核对目标接口的要求，标准产品不含 SLA，官方明确不承诺交易指令准时、免疫晚高峰或不受攻击。

## 常见问题

**广州到香港 IEPL 独享带宽一个月多少钱？**
以 Mkcloud 当前在售套餐为参考，独享带宽 5M 起每月 500 元，10M 每月 700 元，20M 每月 1,320 元，往上到 300M 独享每月 17,400 元。共享带宽门槛更低，1TB 流量档每月 358 元。

**共享 200Mbps 峰值和独享 5M，到底哪个快？**
看用法。短时间传一批文件，共享的峰值更高，体验更好；但如果任务是每天十几个小时持续上传，共享带宽不保证持续跑满，独享 5M 反而能提供确定性的持续速率。官方知识库的原话是「200Mbps 与 5Mbps 对应不同计费资源」，这两个数字本身不可直接比较。

**广港和深港怎么选？**
官方的区分方式是：广港是直连 IEPL，适合从广东本地直接连入；深港走云厂商接入的 IX，需要你已有受支持的云网络做前置。已经在用云厂商且入口条件合适的，深港 IX 入门月付 158 元更省；华南本地直连需求的，走广港。

**流量用超了怎么办？**
计量型套餐按上行、下行双向统计，达到额度后会暂停。可以在后台自助购买流量重置，或者提交工单补差价升级到更高档套餐。

**独享带宽开通要多久？**
官方知识库提到独享产品按持续带宽需求评估，部分独享类产品可能需要一定开通时间，具体以下单后工单沟通为准。共享产品通常开通较快。

**支持退款吗？**
仅质量问题支持退款，需要提交具体的延迟、速度数据作为证据，由商家审核判断。开通后不能更换地域，所以下单前把省份、带宽档位都确认好。
